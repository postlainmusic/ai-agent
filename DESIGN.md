# Antigravity Android UI

## Direction

A mobile-first coding workspace inspired by the interaction model of Acode, but visually rebuilt around the Google Antigravity desktop language: dark, quiet, precise, agent-forward.

## Core layout

- Top bar: workspace identity, search, overflow.
- Left project rail: files and folders without overwhelming the editor.
- Center: code-first editor surface.
- Bottom dock: Files / Agent / Terminal / Run.
- Agent is a first-class workspace surface, not a chat bubble pasted onto an editor.

## Visual tokens

- Ink: `#08090C`
- Panel: `#101217`
- Raised panel: `#151820`
- Hairline: `#242832`
- Text: `#E8EAF0`
- Muted: `#858B9A`
- Antigravity violet: `#9B8CFF`
- Execution cyan: `#72D7FF`

## Product rule

Acode supplies proven mobile-editor patterns and open-source implementation ideas. This project does not attempt to reproduce Acode's visual identity. Antigravity CLI remains the coding agent engine and is bridged to the Android UI through a local process boundary.
